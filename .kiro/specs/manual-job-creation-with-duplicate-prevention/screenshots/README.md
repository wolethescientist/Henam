## Screenshot Guidelines

When capturing screenshots:

1. **Resolution**: Use 1920x1080 or higher
2. **Format**: PNG with transparency where applicable
3. **Content**: 
   - Use realistic but anonymized data
   - Ensure UI is in a clean state (no errors unless demonstrating errors)
   - Highlight relevant UI elements with arrows or boxes if needed
4. **Naming**: Use exact names as referenced in USER_GUIDE.md
5. **Size**: Optimize images to keep file sizes reasonable (<500KB each)

## Adding Screenshots

1. Capture the screenshot following the guidelines above
2. Save it in this directory with the exact filename from USER_GUIDE.md
3. Verify the image displays correctly in the documentation
4. Update this README if adding new screenshots
